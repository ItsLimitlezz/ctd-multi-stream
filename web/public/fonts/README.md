# Fonts

The CTD brand faces, bundled so the web UI needs nothing from outside (CSP `font-src 'self'`):

- Chakra Petch (SemiBold, Bold): display — page titles, the LIVE readout.
- Space Grotesk (Medium, Bold): headings and card titles.
- Space Mono (Regular, Bold): body, labels, buttons.

All three are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).
